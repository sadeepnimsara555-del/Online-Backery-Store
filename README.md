Project Overview

The Online Baker Store System is a simple web-based application designed to simulate a restaurant cashiering and ordering system. It allows users to browse products, create orders, and manage a cart efficiently.

This project demonstrates a basic system architecture using HTML and CSS for the frontend, and Java with Spring Boot for the backend. It also integrates the Bubble Sort algorithm to organize and display order data.

Features

User authentication (Sign Up / Login)

Product browsing

Add-to-cart functionality

Order creation and management

Simple form validation

Sorting of orders using the Bubble Sort algorithm

System Architecture

The system follows a basic layered architecture:

Presentation Layer: HTML and CSS interface

Application Layer: Spring Boot controllers and services

Data Handling: In-memory or basic storage (depending on implementation)

Sorting Mechanism

The system uses the Bubble Sort algorithm to organize order data for display purposes. This demonstrates the integration of a fundamental algorithm within a practical application.

Getting Started
Prerequisites

Java (JDK 8 or higher)

Maven or Gradle

Web browser

Running the Application

Clone the repository:

git clone <your-repo-link>

Navigate to the project directory:

cd online-baker-store

Run the Spring Boot application:

mvn spring-boot:run

Open your browser and go to:

http://localhost:8080/dashboard
Usage Instructions

When the application starts, you must sign up or log in. After authentication, you can browse available products, add items to your cart, and create and manage orders. The system includes basic validation to ensure correct data entry.

System Access

Access the system locally via:
http://localhost:8080/dashboard

Purpose of the Project

This project is intended for learning web application development, understanding Spring Boot architecture, and demonstrating basic sorting algorithms in a practical system.
